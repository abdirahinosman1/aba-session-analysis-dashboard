# ABA Session Performance Analysis

## Overview
This project analyzes session-level behavioral data to evaluate therapist performance, session consistency, and session length effects. Trial-level data was aggregated to session-level to avoid skewed results.

## Key Insights
- Identified performance differences across therapists (~28% gap)
- Consistency alone did not explain performance differences
- Moderate session lengths (3–4 hours) showed highest performance
- Recommended team discussion to identify differences in program implementation

## Tools Used
- Excel (Pivot Tables, Data Cleaning, Conditional Formatting, Dashboard)
