# ABA Session Performance Analysis

## Overview
This project analyzes session-level behavioral data to evaluate therapist performance, session consistency, and session length effects. Trial-level data was aggregated to session-level to avoid skewed results.

Dataset

The original data was recorded for each individual attempt within a session (trial-level data). This data was then grouped into session-level averages to prevent sessions with more attempts from skewing the results

Dashboard

BT D demonstrated the strongest overall performance, maintaining an average success rate of approximately 79.5% across sessions. In contrast, BT C showed lower performance levels, averaging around 51.4%, along with greater variability across sessions. This fluctuation in performance suggests inconsistency in how skills are being applied or maintained over time. The differences observed between therapists may be influenced by factors such as reinforcement timing, prompting strategies, or overall session structure.

## Key Insights
- Identified performance differences across therapists (~28% gap)
- Consistency alone did not explain performance differences
- Moderate session lengths (3–4 hours) showed highest performance
- Recommended team discussion to identify differences in program implementation
